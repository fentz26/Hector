Access token

Optional. Without one, GitHub allows 60 API requests per hour and only public repositories; GitLab uses your GitLab sign-in in this browser, if any. A token gives private repositories and a higher limit. It is stored only in this browser and sent only to that site's API.

Appearance

Toggle the sidebar with Alt+Shift+T, or with Show sidebar in this popup (Hector's toolbar button). Change the shortcut on your browser's extension shortcuts page.

Self-hosted servers

GitHub Enterprise, GitLab (CE/EE) and Bitbucket Server / Data Center. Easiest: open a repository on the server, click Hector's toolbar button and Show sidebar (or press Alt+Shift+T); Hector recognizes the server and asks once to run there. Or add the domain here.

    Needs access to all websites. Hector then checks each page's own markup for GitHub, GitLab or Bitbucket and starts on the ones that are, with no click. Nothing about the pages you visit leaves your browser.

    CI/CD

    CI settings belong to each repository: open the repository, then the sidebar's Settings → This repository. There you can hide the site's own pipelines and connect the repository's TeamCity server, and test the connection. GitLab's TeamCity integration is picked up automatically.

    Backup, restore & reset

    Save Hector's setup to a file — settings, self-hosted servers, each repository's CI/CD and, if you like, bookmarks — and load it after reinstalling or on another browser. The file names your servers and repositories, so keep it private. Access tokens are only included if you choose, encrypted with a passphrase.
